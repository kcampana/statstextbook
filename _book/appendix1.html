16.1 Z-score Table

A z-score table shows the percentage of values to the left of a given z-score on a standard normal distribution. For negative z-scores, find the proportion for the absolute value of the z-score, and subtract that proportion from 1. As an example, for a z-score of -1.11, we find that proportion of +1.11, (which is .8665) and we subtract that value from 1 (which is .1335).

This table provides critical values for an F-test.Each column provides critical values for the numerator degrees of freedom (i.e., your within degrees of freedom, which should be the number of groups minus 1). The rows provides critical values for the denominator degrees of freedom. So, if you are testing F(2,20), the critical value is 3.49.
